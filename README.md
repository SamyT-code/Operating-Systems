# CSI 3131 – Operating Systems Assignments

This repository contains four assignments completed for the Operating Systems course (CSI 3131) at the University of Ottawa. Each assignment explores a core topic in OS development and simulation:

- **D1 – System-Level File Operations (C):**  
  Custom implementation of the `cp` command using low-level system calls (`open`, `read`, `write`, `close`).

- **D2 – Java Threading:**  
  Multithreaded computation of Fibonacci and prime numbers using custom `Thread` subclasses.

- **D3 – TA-Student Synchronization Simulation (Java):**  
  Simulation of a help-desk system using semaphores and locks to manage concurrent access to shared resources.

- **D4 – Paging Algorithms & Producer-Consumer (Java/Python):**  
  FIFO and LRU page replacement algorithms simulated in both Java and Python, along with a thread-based producer-consumer model generating Catalan numbers.

Each assignment demonstrates OS-level principles like concurrency, synchronization, memory management, and file system operations through hands-on coding.
